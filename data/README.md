# Dataset setup

Download the [Brain Tumor MRI Dataset by Masoud Nickparvar](https://www.kaggle.com/datasets/masoudnickparvar/brain-tumor-mri-dataset) directly from Kaggle and follow its current terms and attribution requirements.

Extract the dataset so this directory contains `Training/` and `Testing/`, each with `glioma/`, `meningioma/`, `notumor/`, and `pituitary/` class directories. Dataset images are intentionally excluded from Git.

Alternatively, set the `BRAIN_TUMOR_DATASET_DIR` environment variable to the extracted dataset root.
